How word formation works

In a word-formation task you get a root word in capitals and must change it so it fits the gap grammatically and logically. You may need to add a prefix, a suffix, or both — and sometimes change the spelling of the root.

1 · Noun suffixes

  • -tion / -sion / -ation: pollute → pollution, emit → emission
  • -ment: commit → commitment
  • -ness / -ity: aware → awareness, scarce → scarcity
  • -ance / -ence: rely → reliance, depend → dependence
  • -er / -or / -ist: pollute → polluter, activism → activist
  • -dom / -th: wise → wisdom, grow → growth

2 · Adjective suffixes

  • -able / -ible: afford → affordable, access → accessible
  • -al / -ic / -ical: environment → environmental, catastrophe → catastrophic
  • -ful / -less: waste → wasteful, point → pointless
  • -ive / -ous: persuade → persuasive, danger → dangerous
  • -ing / -ed: astonishing (causes the feeling) vs. astonished (has it)

3 · Negative prefixes

  • un- the most common: unrealistic, unaware
  • in- (Latin roots): inadequate, inability
  • im- before p, m, b: impossible, immature, imbalance
  • il- before l: illegal, illogical
  • ir- before r: irreversible, irresponsible
  • dis-, mis- (wrongly), non-: disobey, mislead, non-renewable

4 · Verbs and adverbs

  • -ise/-ize: modern → modernise · -ify: pure → purify
  • -en: strong → strengthen · en-: danger → endanger, able → enable
  • -ly for adverbs: economic → economically (note -ically), argue → arguably
  • Prefixes of meaning: over-, under-, re-, out-, co-, counter-, mal-, pre-, post-, anti-

Exam hack — 4 questions to ask at every gap

  1. Which part of speech? Look at the words around the gap: a / the + ___ + of = noun; very / more + ___ = adjective; ___ + verb = adverb.
  2. Singular or plural? Is there a, many, or a plural verb?
  3. Positive or negative? Read the whole sentence — words like but, however, despite often signal a negative prefix.
  4. Spelling! Check changes to the root: pronounce → pronunciation, maintain → maintenance, deny → undeniably.
